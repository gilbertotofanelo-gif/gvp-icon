GVP

📱 Para Android

  1. Abra esta página no navegador Chrome.
  2. No menu (⋮), escolha "Adicionar à tela inicial".
  3. Confirme o nome do ícone como GVP.
  4. O ícone será criado na tela inicial. Toque nele para abrir o sistema.

🍎 Para iOS (iPhone/iPad)

  1. Abra esta página no navegador Safari.
  2. Toque no botão Compartilhar (ícone quadrado com seta para cima).
  3. Selecione "Adicionar à Tela de Início".
  4. Confirme o nome do ícone como GVP.
  5. O ícone será criado na tela inicial. Toque nele para abrir o sistema.
Depois de adicionar, basta tocar no ícone GVP criado na tela inicial para acessar o sistema.
